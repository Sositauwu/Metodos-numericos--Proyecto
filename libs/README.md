# Bibliotecas locales

- **Chart.js**: motor de gráficas existente.
- **SheetJS / XLSX**: importación y exportación de hojas de cálculo existente.
- **GSAP 3.15.0**: animaciones de `motion.js`, copiado de `gsap/dist/gsap.min.js` del paquete npm oficial. Se conserva su cabecera de distribución. Fuente: https://github.com/greensock/GSAP. Licencia y condiciones oficiales: https://gsap.com/standard-license/.

La aplicación carga estas copias locales; no necesita un CDN para ejecutarse.
